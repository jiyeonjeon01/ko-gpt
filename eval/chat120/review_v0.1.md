## 1. f05 · 상식 사실

| 항목 | 내용 |
|---|---|
| 원문 | 물은 몇 도에서 끓어? |
| 현재 허용 답 | "100도", "섭씨 100도" (note: 1기압 기준, 조건을 안 붙여도 정답) |
| 문제 1 | 질문에 압력 조건이 없다. "기압에 따라 다르다"는 사실상 더 정확한 답인데, 현재 기준으로는 정답어가 없어 자동 지표에서 0이 된다 |
| 문제 2 | "100℃", "100°C" 표기는 자동 지표의 허용 답 "100도"와 일치하지 않는다 |
| 문제 3 | "화씨 212도"는 맞는 답인데 허용 목록에 없다 |
| **권장안** | 질문은 그대로 둔다 (일상 질문 형태 유지). 허용 답에 "100℃", "100°C", "100 °C", "212°F", "화씨 212도"를 추가한다. 채점 기준 note: "100도(1기압) 언급 = 2점, 기압 조건만 말하고 100도 언급 없음 = 1점, 다른 온도 = 0점" |
| 다른 안 | 질문을 "1기압에서 물은 섭씨 몇 도에서 끓어?"로 바꿔 모호함을 없앤다. 다만 일상 질문 형태가 아니게 된다 |

## 2. f09 · 상식 사실

| 항목 | 내용 |
|---|---|
| 원문 | 한국에서 가장 높은 산은? |
| 현재 허용 답 | "한라산", "백두산" (남한 기준 한라산, 한반도 기준 백두산 모두 정답) |
| 문제 1 | "한국"을 대한민국 실효 지배 지역으로 보면 한라산(1,947m), 한반도로 보면 백두산(2,744m)이다. 두 답을 모두 허용하면 문항의 변별력이 낮아진다 |
| 문제 2 | 자동 지표는 둘 중 하나만 있으면 정답이다. "백두산이 아니라 한라산" 같은 문장도 정답으로 센다 (부정 표현은 자동으로 구별하지 못한다. 5-3) |
| 문제 3 | ko20의 ko13("질문: 한국에서 가장 높은 산은 무엇인가요?")과 같은 사실을 묻는다. 평가끼리의 겹침이라 오염은 아니고, 사전학습 이어 쓰기와 SFT 응답을 비교하는 데 쓸 수 있다 |
| **권장안** | 질문을 **"남한에서 가장 높은 산은?"**으로 바꾸고, 허용 답은 "한라산" 하나로 한다. 사실이 하나로 정해진다 |
| 다른 안 A | 그대로 둔다 (두 답 허용) |
| 다른 안 B | "한반도에서 가장 높은 산은?" + "백두산" |

| 다른 안 | 그대로 둔다. 자동 지표에서 오탐 가능성이 있다는 점을 보고서에 적는다 |

## 5. 검토 중 찾은 것: 자동 "정답 포함률"의 허용 답 문제

### 5-1. 숫자 경계 (고쳤음)
- 허용 답 "5"가 "15"에, "8시"가 "18시"에, "12"가 "120"에 들어 있어 오답을 정답으로 셌다.
- 영향을 받는 문항: m01, m02, m04, m09, m12, m13, m14, f04, f12, f15, g05, g08 등 숫자 정답 문항 대부분
- **조치 (chat_metrics.py와 rubric.md 정의를 고침, 응답 생성 전):** 숫자로 시작·끝나는 허용 답은 앞뒤에 다른 숫자가 붙으면 인정하지 않는다. 테스트를 추가했다.

### 5-2. 너무 짧아 다른 단어에 들어 있는 허용 답 (결정 필요)

| id | 원문 | 허용 답 | 문제 | 권장안 |
|---|---|---|---|---|
| f13 | 얼음이 녹으면 무엇이 돼? | "물" | "동물", "물질", "물체"에도 들어 있다 | 허용 답을 "물이 돼", "물이 됩니다", "물이에요", "물로", "물이"로 바꾼다. 또는 그대로 두고 사람 채점에 맡긴다 |
| k09 | 파이썬 딕셔너리에 어떤 키가 있는지 확인하려면? | "in", "key in d" | "in"은 거의 모든 영어 단어(print, string)와 코드에 들어 있어 사실상 늘 정답이 된다 | 허용 답을 "in d", "in dict", "in my_dict", ".keys()", ".get(", "__contains__"로 바꾼다 |
| m15 | 모든 고양이는 동물이다. 나비는 고양이다. 그러면 나비는? | "동물이다", "동물" | "동물이 아니다"도 정답으로 센다 (부정 표현) | 그대로 두고 5-3 한계로 기록. 사람 채점이 최종 판단 |

그 밖의 짧은 허용 답("서울", "세종", "목성", "도쿄", "동해", "철수")은 다른 흔한 단어에 거의 들어 있지 않아 그대로 둔다.

### 5-3. 자동 지표의 남는 한계 (기록)
- 부정·정정 표현("A가 아니라 B")은 구별하지 못한다. 정답 포함률은 **보조 지표**이고, 최종 판단은 사람 채점의 사실 정확성이다 (rubric 1절에 이미 명시).
