# chat120 초안 v0.3 최종 검토 기록

- **작성:** 2026-11-09
- **검토자:** Claude가 120문항 전체의 원문·정답 기준·안전 조건·자동 판정 규칙을 다시 읽었다.

  - 사용자는 검토 자료(`review_v0.1.md`, `review_v0.2.md`, `draft_v0.2_table.md`)와 권장안을 확인하고 고정을 승인했다 (2026-11-09).

- **v0.2는 보존했다.**

## 1. v0.2 → v0.3 변경 (2문항, 자동 판정만)

| id | 문제 | 변경 |
|---|---|---|
| k02 | 허용 답 "len"이 "length", ".length"(다른 언어, 오답) 안에서도 정답으로 맞는다 | `accept_regex`: 단어로서의 len만 인정 (`len(…)`, "len 함수") |
| k04 | 허용 답 "sorted()"가 흔한 정답 `sorted(lst)`와 맞지 않는다 (괄호 안에 인자가 있음) | `accept_regex`: `sorted(…)`, `.sort(…)` |

- 사용자 발화, 범주, 기대 언어, 다른 118문항은 v0.2와 같다.
- `rubric.md`는 제목만 "v0.3-draft, frozen_v1과 함께 고정"으로 바꿨다. 정의는 같다.

| id | 내용 | 판단 |

| m01, m04, m07 등 숫자 문항 | 응답이 질문의 숫자를 되풀이해도 허용 답과 겹치지 않는지 확인 | 겹치지 않는다. 예: m12 질문 "1부터 5까지"에는 정답 "15"가 없다 |
