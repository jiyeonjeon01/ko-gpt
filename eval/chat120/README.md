## 절차: 초안 → 검토 → 고정 → 사용

1. **초안 (끝남, 2026-11-07):** 문항·정답 기준·안전 조건을 작성했다.
2. **자동 검사 (끝남):** `scripts/eval_overlap.py`
   - 세트 안 중복
   - 기존 학습·평가 데이터와의 중복: SFT 후보, KoBEST·HellaSwag·ARC·PIQA, ko20 프롬프트
   - 결과: `runs/phase2/prep/eval_overlap.json`
3. **사람 검토 (사용자):** 문항·정답 기준·채점 기준을 읽고 고칠 것을 정한다. 고치면 `draft_v0.2.json`으로 새로 저장한다.
4. **고정:** `python3 scripts/freeze_eval_set.py eval/chat120/draft_v0.X.json`
   - `frozen_v1.json`과 SHA-256, 고정 시각, 고정에 쓴 초안 이름이 기록된다.
   - 이미 고정본이 있으면 멈춘다.
5. **사용:** SFT 전후 모델의 응답 생성, 자동 지표, 사람 채점은 **고정본으로만** 한다.

## 규칙

- **고정 전에는 어떤 모델의 응답도 생성하지 않는다.** 2026-11-09 현재 생성한 적 없다.
- **고정 뒤에는 문항·`reference`·`safety`·`rubric.md`를 고치지 않는다.**
  - 문제를 발견하면 `frozen_v2.json`을 새로 만든다. 변경 이유와 "모델 응답을 보기 전/후"를 기록한다.
  - 응답을 본 뒤의 수정은 v1 결과와 비교하지 않는다.
- **SFT 학습 데이터에 평가 문항을 넣지 않는다.**
  - SFT 데이터를 만들 때 `scripts/eval_overlap.py`의 `EvalGuard`(발화·문단, 문장, 바꿔 쓴 질문 정규식 3단계)로 평가 문항과 비슷한 대화를 뺀다.
  - 데이터를 만든 뒤 `scripts/eval_contamination.py`로 문장 단위 겹침과 사실 노출을 다시 확인한다.
  - 뺀 목록은 기록한다.
- S11 직접 작성 데이터는 평가 문항과 비슷한 질문을 피해서 쓴다 (`S11_작성가이드.md`).
